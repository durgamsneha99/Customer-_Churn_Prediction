# Customer Churn Prediction

## Project Overview

This project predicts whether a customer is likely to leave a telecom service using Machine Learning.

## Objectives

* Analyze customer churn patterns.
* Perform Exploratory Data Analysis (EDA).
* Train a Random Forest Classifier.
* Evaluate model performance using Accuracy, ROC-AUC, and Classification Report.

## Dataset

* Telco Customer Churn Dataset
* Total Records: 7043
* Features: 21

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Project Workflow

1. Load Dataset
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Model Training
6. Model Evaluation
7. Feature Importance Analysis

## Machine Learning Model

* Random Forest Classifier

## Model Performance

* Accuracy: **78.92%**
* ROC-AUC Score: **0.6834**

## Visualizations

* Customer Churn Distribution
* Monthly Charges vs Churn
* Contract Type vs Churn
* Confusion Matrix
* Feature Importance

## Conclusion

The Random Forest model successfully predicts customer churn with approximately 79% accuracy. The project demonstrates data preprocessing, visualization, machine learning model training, and evaluation techniques for customer retention analysis.
